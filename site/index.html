kiln

Configures a fresh Debian 13 (trixie) amd64 machine. At the machine's console, run:

wget -qO- https://satya-janghu.github.io/kiln/i | sudo bash

As root (no sudo yet; log in as root or use su -):

wget -qO- https://satya-janghu.github.io/kiln/i | bash

Read the script first: install.sh. Source and releases: github.com/satya-janghu/kiln.
